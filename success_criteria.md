# Success Criteria

The project is complete when:

1. User can sign up.

2. User can upload a PDF tender.

3. System extracts text.

4. Eligibility Agent runs.

5. Risk Agent runs.

6. Requirements Agent runs.

7. Proposal Agent runs.

8. Results page displays:

- Eligibility Score
- Risks
- Required Documents
- Proposal Outline

9. Application is deployed on Vercel.

10. Demo video can be recorded.

Anything beyond this is optional.
